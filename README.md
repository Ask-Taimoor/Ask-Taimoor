# Hi, I'm Taimoor 👋

**WordPress & Divi plugin developer.** I build Divi 4 and Divi 5 modules and plugins, and I port Divi 4 plugins to Divi 5. I also build the services around them: cloud APIs, AI tools and browser extensions.

Most of my work is for agencies and their products, so the code stays private. Here's what I work on.

## What I build

- **Divi 5 modules and extensions.** Custom modules, settings panels and Visual Builder tools, written in React and PHP.
- **Divi 4 → Divi 5 ports.** I move plugins to Divi 5 so they look and behave the same as before.
- **WordPress plugins.** Admin tools, blog and content tools, multilingual support, event calendars, tables, tabs and table-of-contents builders.
- **Cloud services.** Screenshot and PDF APIs, and website monitoring, built on Cloudflare Workers.
- **AI tools.** MCP servers and tools that work alongside Divi 5's AI Agent.
- **Chrome extensions** for team workflows.

I handle the full process: planning, building, QA, security and performance reviews, release builds and support.
